# TC-003 — Оформлення замовлення (Place Order)

**Модуль:** Checkout / Place Order  
**Тестувальник:** Saveliy Protsenko  
**Дата:** 2026-05-01  
**Передумови:** Користувач авторизований, в кошику є товар

---

## TC-003-01 — Успішне оформлення замовлення з коректними даними

| Поле | Значення |
|------|----------|
| **Пріоритет** | High |
| **Тип** | Позитивний |

**Тестові дані:**
| Поле | Значення |
|------|----------|
| Name | John Doe |
| Country | Armenia |
| City | Yerevan |
| Credit card | 4111111111111111 |
| Month | 05 |
| Year | 2027 |
| CVV | 123 |

**Кроки:**
1. Перейти до кошика (Cart)
2. Натиснути **Place Order**
3. Заповнити всі поля форми тестовими даними
4. Натиснути **Purchase**

**Очікуваний результат:** З'являється модальне вікно з підтвердженням замовлення. Відображається ID замовлення, сума та дата.

**Статус:** ✅ Pass

## TC-003-02 — Оформлення замовлення з порожньою формою

| Поле | Значення |
|------|----------|
| **Пріоритет** | High |
| **Тип** | Негативний |

**Кроки:**
1. Перейти до кошика
2. Натиснути **Place Order**
3. Не заповнювати жодне поле
4. Натиснути **Purchase**

**Очікуваний результат:** Система відхиляє форму та показує помилки валідації для обов'язкових полів.

**Статус:** ⚠️ Fail — замовлення оформлюється без даних (див. BUG-002)

## TC-003-03 — Оформлення замовлення без заповнення поля Name

| Поле | Значення |
|------|----------|
| **Пріоритет** | High |
| **Тип** | Негативний |

**Кроки:**
1. Перейти до кошика
2. Натиснути **Place Order**
3. Залишити поле **Name** порожнім

## TC-003-05 — Закриття форми замовлення без збереження

| Поле | Значення |
|------|----------|
| **Пріоритет** | Low |
| **Тип** | Позитивний |

**Кроки:**
1. Перейти до кошика
2. Натиснути **Place Order**
3. Частково заповнити форму
4. Натиснути **Close** або хрестик модального вікна

**Очікуваний результат:** Форма закривається. Товари в кошику залишаються без змін. Дані форми не зберігаються.

**Статус:** ✅ Pass
