# BUG-002 — Форма замовлення приймається з порожніми полями

## Опис

При оформленні замовлення форма успішно надсилається навіть якщо всі поля залишені порожніми. Відсутня будь-яка валідація обов'язкових полів (ім'я, картка, місяць, рік, CVV, місто, країна).

---

## Кроки відтворення

1. Відкрити https://pizzashop
2. Додати будь-який товар до кошика
3. Перейти до кошика → натиснути **Place Order**
4. У модальному вікні **не заповнювати жодне поле**
5. Натиснути кнопку **Purchase**

---

## Очікуваний результат

Система має відобразити помилку валідації та не дозволити надіслати форму без заповнення обов'язкових полів (Name, Credit card, Month, Year, CVV).

---

## Фактичний результат

Форма успішно надсилається. З'являється повідомлення про успішне замовлення з порожніми даними покупця.

---

## Серйозність та вплив

- 🔴 **Critical** — можливе оформлення "фейкових" замовлень без реальних даних
- Порушення бізнес-логіки: замовлення без платіжних даних не може бути оброблене
- Потенційний вектор для спаму/зловживань
